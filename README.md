## 🛠️ En qué ando

- **Plataforma como producto:** los equipos piden un topic de Kafka o un secreto con un manifiesto, y Crossplane / External Secrets hacen el resto.
- **Build once, deploy many:** la imagen se construye una vez en el PR y se promueve igual por develop → qa → producción.
- **Cero llaves:** Workload Identity en todos lados, de GitHub Actions a los pods.
- **Costos a la vista:** reportes multi-cloud para que cada equipo sepa cuánto gasta y por qué.
